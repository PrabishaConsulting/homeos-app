# HomeOS for Android

**[⬇ Download the latest APK](https://github.com/PrabishaConsulting/homeos-app/releases/latest/download/homeos.apk)**

1. Open the link on your Android phone.
2. Allow "Install unknown apps" for your browser when asked.
3. Open the downloaded file and tap **Install**.

The app tells you when a new version is available and updates itself.
